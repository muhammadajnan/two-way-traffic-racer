🚗 Two-Way Traffic Racer

A simple 2D car racing game developed using Java and Swing. The player controls a blue car and avoids incoming traffic on a two-way road. The game features a scoring system, increasing difficulty, pause functionality, and a restart option.

🎮 Game Preview

Game: Two-Way Traffic Racer
Language: Java
GUI Framework: Java Swing
Project Type: Java Mini Project

✨ Features

* 🚘 Player Control: Move the blue car left and right using the arrow keys.
* 🚗 Traffic System: Avoid red and purple cars moving along the road.
* 🏆 Scoring System: Earn points by passing traffic cars.
* ⚡ Increasing Difficulty: Game speed increases as your score grows.
* ⏸️ Pause and Resume: Press P to pause or resume the game.
* 🔄 Restart Game: Restart after a crash or press R at any time.
* 💥 Collision Detection: The game ends when your car collides with another car.
* 🎨 Graphics: Features a road, dashed yellow center lines, car lights, and a green background.

🚀 How to Run the Project

Step 1: Clone the Repository

git clone https://github.com/YOUR-USERNAME/Two-Way-Traffic-Racer.git

Replace YOUR-USERNAME with your GitHub username.

Step 2: Open the Project

Navigate to the project directory:

cd Two-Way-Traffic-Racer

Step 3: Compile the Java Program

If your file is named Main.java:

javac Main.java

If your file is named CarGame.java:

javac CarGame.java

Step 4: Run the Game

If the class is named CarGame, run:

java CarGame

The game window will open, and you can start playing!

🧠 How the Game Works

1. The game window is created using Java Swing.
2. A timer updates the game approximately every 20 milliseconds.
3. The road markings and traffic cars move to create the appearance of driving.
4. The player moves the blue car using the left and right arrow keys.
5. The score increases when traffic cars pass the bottom of the screen.
6. Collision detection checks whether the player’s car hits another car.
7. The game ends when a collision occurs.
8. The player can restart the game and try to achieve a higher score.
